# Factorial of a Number

This project is a simple Python program to calculate the factorial of a number.

## Program

The program calculates the factorial of the number **5**.

## Files

* `app.py` – Python program to calculate the factorial.
* `jenkinsfile` – Jenkins Pipeline file used to build and test the program.

## Output

```text
Number: 5
Factorial: 120
```

* Python
* Git
* GitHub
* Jenkins
